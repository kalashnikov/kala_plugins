# sharpen

改寫自 pstack（poteto）的 sharpen。

使用者要這個任務更深的版本，不是更大的版本。任務是參數裡的描述；沒給參數就用對話中最近的任務。

重寫之前，先做四件事：

1. 說出這個領域的頂尖專家在這裡會做、而使用者沒要求的事。
2. 指出他們會從哪個**最原始的素材**下手，取代已經被別人消化過的二手資料。
3. 點名他們會用的具體方法和工具。
4. 說出除了你和使用者之外，**什麼東西**能證明結果是對的（例如原始史料、獨立資料源、實際跑出的數字、第三方驗證）。

然後重寫使用者的 prompt，明確要求這些。

重寫後的 prompt 要：

- 要求 agent 對「實驗能決定」的選擇先做原型實測，再依觀察結果推薦一個選項。
- 把「實驗決定不了」的產品或偏好選擇留給使用者決定，列出選項就好。

用繁體中文寫。只輸出四點分析和重寫後的 prompt，不要直接開始執行任務。
